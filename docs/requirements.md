# Requisitos do Sistema - Nexus Manager

## Sobre o projeto

O Nexus Manager é um sistema de gestão empresarial desenvolvido para auxiliar pequenas empresas no controle de clientes, produtos e vendas.

## Problema

Muitas empresas utilizam planilhas ou controles manuais, dificultando o acompanhamento de informações e a tomada de decisões.

## Objetivo

Criar uma plataforma que centralize informações comerciais e facilite o gerenciamento do negócio.

## Funcionalidades principais

- Cadastro de usuários
- Login e autenticação
- Controle de clientes
- Controle de produtos
- Registro de vendas
- Dashboard com indicadores

## Usuários do sistema

### Administrador

Responsável por gerenciar usuários, produtos, clientes e relatórios.

### Funcionário

Responsável por cadastrar clientes e registrar vendas.
